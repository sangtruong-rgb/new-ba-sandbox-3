# Việc

A to-do list: one person, a laptop and a phone. Vietnamese UI.

## Stack

Hono on Node with SQLite (better-sqlite3) for the API; React 19 with react-router-dom on Vite;
`@hono/vite-dev-server` sends only `/api/*` to `server/app.ts`. Vitest (jsdom) for unit tests,
Playwright for e2e, ESLint with typescript-eslint, TypeScript strict.

## Commands

- `npm run dev`: Vite on `PORT` (5173 when unset), every interface.
- `npm test`: every Vitest test under `server/` and `src/`.
- `npm run e2e`: Playwright; starts its own `npm run dev` with `NODE_ENV=test` and a new `DATABASE_PATH`.
- `npm run lint`
- `npm run typecheck`

## Layout

- `server/`: `app.ts` (createApp, default export), `auth/` (users, sessions), `tasks/store.ts`,
  `registry.ts` (loads every feature `server.ts`), `testing.ts` (testApp for route tests), `types.ts`.
- `src/app/`: App, session gate, feature registry, slots, logger, `styles/` (the only global CSS: tokens).
- `src/shared/`: api client, task store, list view, time, task rules, form UI.
- `src/pages/<page>/page.tsx`: the frame of a page and its slots; styles in `page.module.css`.
- `src/pages/<page>/features/<feature>/`: a feature of one page.
- `src/features/<feature>/`: a feature of several pages.

## A feature folder

- `index.ts` exports `{ id, slots: [{ slot, order, Component }], routes, storageKeys, shortcuts }`;
  it is found on disk and rendered in its slots, each in its own error boundary.
- `server.ts` (optional) exports `{ id, routes: [{ method, path }], register(app, deps) }` with full
  paths such as `/api/tasks`.
- Its components, CSS modules (`*.module.css`) and tests live in the folder.
- Log only through `createLogger` from `src/app/log.ts`; lines start with `[<page>/<feature>]`.
- Colours only from the tokens in `src/app/styles/tokens.css`.

## Import rule

Lint enforces it: a feature never imports another feature; a page never imports another page's
feature; only `server/`, a feature's `server.ts` and a feature's `*.test.ts` (for `server/testing.ts`)
import from `server/`. Shared code goes in `src/shared/`.

## Tests

Name each test `<page>/<feature> · C<n> · …` (the criterion it shows). Unit tests sit beside the
file they test (`x.test.ts`); e2e tests under `e2e/`, importing `test` from `e2e/support/fixtures.ts`.

The repository map is `docs/ARCHITECTURE.md`, generated by the factory; do not edit it by hand.
